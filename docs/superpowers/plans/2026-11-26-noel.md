> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Ba task A/B/C chạy SONG SONG trong worktree riêng, controller gộp vào nhánh `feat/noel`.

**Goal:** v1.0.0 — giao diện Noel (thay hẳn băng tuyết) + tuyết rơi toàn app; 71 từ mới / 6 chủ đề thay 45 từ cũ; 18 câu nói chuyện (giữ tên, tuổi; 16 mới, có câu kèm hình); So sánh cấp 1 dùng hình Noel; toàn bộ giọng tạo lại bằng máy local: tiếng Việt **VieNeu-TTS giọng "Trúc Ly"**, tiếng Anh **Kokoro-82M**.

### Task A — Công cụ tạo giọng local (chỉ `tool/`, `test/tool/`)
- `tool/gen_voice.dart`: nhà cung cấp mặc định mới, giữ cấu trúc clip theo đoạn (`content/audio/<sha1(lang|text)[:16]>.ogg`, Opus mono 32 kbps, `index.json` `granularity: "part"`), cache MP3/WAV theo khóa đoạn + provider + voice trong `build/voice-parts/`.
  - `vi` → VieNeu-TTS Gradio tại `VIENEU_URL` (mặc định `http://127.0.0.1:7860`), endpoint `/wrapper` qua `gradio_client` (tham số theo thứ tự: text, voice `"Trúc Ly"`, None, "", "Standard (Một lần)", False, 1, temperature 0.7, 256, True; trả về đường dẫn wav). Helper Python `tool/tts/vieneu_batch.py` nhận job JSON `{items:[{text,out}]}`, chạy 4 client song song (ThreadPool 4), ghi wav; gọi bằng `uv run --quiet --with gradio_client python -I tool/tts/vieneu_batch.py job.json`. Câu không kết thúc bằng . ! ? thì thêm "." khi gửi (từ đơn đọc trọn vẹn hơn).
  - `en` → Kokoro-82M (`hexgrad/Kokoro-82M`, cache `~/.cache/huggingface`), giọng nữ `af_heart`, speed 0.9, helper `tool/tts/kokoro_batch.py` (mẫu: `/Users/locnguyen/orca/projects/claude-tiktok/tools/kokoro/speak.py` — đọc để học cách gọi `KPipeline`, chuẩn hóa âm lượng, thêm "." cho từ đơn), chạy bằng Python `KOKORO_PYTHON` (mặc định `/Users/locnguyen/orca/projects/claude-tiktok/.venv-kokoro/bin/python`).
  - Mỗi đoạn: cắt lặng đầu/cuối (ffmpeg `silenceremove`), thêm 0,15 s lặng hai đầu, chuẩn hóa âm lượng hai giọng ngang nhau, mã hóa Opus như cũ.
  - Cờ giữ nguyên `--prune --dry-run --limit --only`; thêm `--provider local|vbee` (mặc định `local`; đường Vbee cũ giữ nguyên để dự phòng); `--allow-api` chỉ áp dụng Vbee. Thiếu server/Python → báo lỗi tiếng Việt rõ ràng, thoát mã 2.
  - Test: tách job, khóa cache theo provider/voice, xử lý lỗi helper (mock Process), không gọi mạng thật trong test.
  - Thử thật với `--only` 3 đoạn vi + 3 đoạn en (server đang chạy), nghe-độ dài hợp lý, KHÔNG chạy toàn bộ (controller chạy sau khi gộp). Commit `feat: local voice generation (VieNeu + Kokoro)`.
